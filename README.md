# TekkenRU

Десктоп-справочник по Tekken 8 на русском: гайды, комбо, фреймдата, видео приёмов
и экран «Матчап» с автоопределением соперника.

## Команды

```bash
npm install
npm start          # собрать и запустить
npm test           # тесты разбора нотации
npm run pack:win   # портативная сборка под Windows x64 в release/
```
